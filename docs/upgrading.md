# 升级与回归验证

## 先确定要升级到哪里

当前补丁验证组合为 TeslaMate **4.5.0** 与中文版仪表盘 **v1.13.0**。如果你是从较旧官方 TeslaMate 接入本补丁，应先把官方镜像改为 `teslamate/teslamate:4.5.0`，再执行：

```bash
cd /你的/TeslaMate/Compose目录
docker compose pull
docker compose up -d
docker compose ps
```

确认 TeslaMate、数据库和 Grafana 都处于运行状态后，再运行本仓库的整合安装器。不要使用未在 [兼容性说明](compatibility.md) 标明的“latest”或更高版本。

TeslaMate 和 Grafana 镜像升级不会直接修改容器外的本仓库脚本；但上游页面结构、前端文件名及仪表盘标题可能变动，仍需验证。

## 升级前

1. 备份数据库和现有 Nginx 配置。
2. 记录当前镜像版本。
3. 确认自定义脚本放在容器外目录，不在容器文件系统中直接修改。

## 升级后检查

1. 原生 TeslaMate：打开控制台、检查中文菜单和高德跳转。
2. Grafana：确认导航位置、排序和两列菜单正常。
3. 检查 Nginx 错误日志与浏览器控制台。
4. 若前端菜单不再匹配，先停用注入脚本，保留原始功能，再按新版本修订补丁。

## 原生地图的重要说明

中国地图瓦片与坐标转换需要修改 TeslaMate 的版本相关前端组件。切勿把某一版本已编译的 `app-*.js` 直接复制到另一版本。这个仓库当前只发布通用 UI 与跳转补丁；版本适配应以可审查的补丁/脚本方式单独发布。
