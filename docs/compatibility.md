# 兼容性与版本策略

## 当前稳定版本

| 组件 | 已验证版本 | 状态 |
| --- | --- | --- |
| 本补丁 | v1.2.2 | 当前稳定版；包含中文版仪表盘的一次整合安装脚本 |
| TeslaMate 官方 | 4.5.0 | 已完整验证 |
| Grafana 中文版仪表盘 | v1.13.0 | 已完整验证 |
| Grafana | 使用中文版仪表盘所附/要求的版本 | 已验证导航与仪表盘 API |

`4.5.x` 并不代表所有小版本均可直接套用原生地图补丁：高德底图适配严格锁定 TeslaMate **4.5.0** 的前端资源校验值。其他 4.5.x 版本仍可使用通用的原生菜单、高德位置跳转、Grafana 分类与导航补丁，但不要运行地图资源补丁。

## 支持范围

- **通用 UI 补丁**：原生控制台中文分组、位置图标跳转高德地图及 WGS-84 → GCJ-02 纠偏；以 TeslaMate 4.5.0 为已验证基线。
- **Grafana 补丁**：共享导航（7 项顶栏）、分类标签（5 个分类）、长菜单分列、帮助菜单和概览空数据提示；以 `teslamate-chinese-dashboards` v1.13.0 的仪表盘 UID 为已验证基线。
- **高德底图补丁**：仅 TeslaMate 4.5.0。脚本会先校验原始 asset 的 SHA-256；不匹配会停止，不会写入输出文件。

## 上游升级后的规则

1. 先按照上游项目各自的升级说明升级。
2. 不要复用旧版本生成的 `app-*-amap.js`。
3. 运行 Grafana 分类与导航脚本前先备份；脚本会再创建一份仪表盘 JSON 备份。
4. 新版 TeslaMate 或中文版仪表盘尚未列入本页时，视为**未验证**，请等待对应 Release 或自行测试后再部署。

## 版本号含义

- 补丁主版本：可能有安装方式或分类结构不兼容变更。
- 次版本：新增兼容的 TeslaMate/中文版仪表盘版本，或新增可选功能。
- 修订版本：文档、样式、排序与不改变安装流程的修复。
